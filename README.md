# YouTube-Downloader
YouTube videók letöltése mp4 vagy mp3-ban.


> [!WARNING]
> A program jelenleg nem működő képes, mert a függőségek frissítése nem automatikus. A program teljes újraírásával lesz javítva amire 2027-ben kerül sor.

## Hogy működik?
A program a [YoutubeExplode](https://github.com/tyrrrz/youtubeexplode) NuGet csomaggal lekéri a videó adatait majd [ffmpeg](https://github.com/ffmpeg/ffmpeg) segítségével átkonvertálja mp3 vagy mp4 formátumba.
